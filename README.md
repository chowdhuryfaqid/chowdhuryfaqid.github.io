# chowdhuryfaqid.github.io

Personal portfolio for Chowdhury Faqid Ahmed Tofail: Business Intelligence & Retail Analytics.

A single static page (`index.html`) with no build step, served by GitHub Pages.

## Files
- `index.html`: the whole site (HTML, CSS and a little JavaScript)
- `.nojekyll`: tells GitHub Pages to serve the files as they are

## Updating
- Experience, strengths and numbers are plain text in `index.html`; search for the section id (`#experience`, `#strengths`, `#projects`).
